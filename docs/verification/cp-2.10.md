# CP-2.10 — canonical backup and basic telemetry

PASS, 2026-10-05. Migration 008 adds snapshot/chunk receipts and a bounded, SQL-enforced mutation barrier on the 20 current canonical tables. Historical migrations 001–007 are unchanged. Export uses owner-scoped rowid chunks of at most 25 rows and 64 KB, a manifest with cut sequence, migration hashes, exact counts and SHA-256 hashes. The pilot ceiling is 200 chunks / 2 MiB of row data and the barrier expires after two minutes. An expired or incomplete cut cannot become VERIFIED. A failed export releases its own barrier; automatic expiry allows writes after a disconnected browser. Sessions, OIDC intents/bootstrap grants, raw owner subject and reusable worker credential hashes are excluded. Config contains secret references, never secret values.

Restore is an offline administrative operation into a separate empty database, never an in-place production overwrite. All chunks, columns, owner binding and manifest are validated before writes. Cyclic Item/ItemRevision pointers are rebuilt after row import. Accepted run/selection/config history and job arrival origin survive. Interrupted leases become RETRY_WAIT with a higher fence; old worker credentials are revoked and owner sessions are absent. Indices are recreated by the checksummed migration ledger. Failed restore targets are not activated.

Actual deployment: version `27cd1689-0969-4877-a258-c686aab7c264`, eight migrations, remote quick check / FK PASS. The authenticated owner browser initiated the export on the deployed application. The browser tool timed out during the download, but the actual file was saved in the owner's private Downloads medium. Independently verified portable backup `68e7e814-6fce-44ca-b233-c006286cfdfa`: 1501 rows / 518696 bytes of row data; restored to isolated SQLite with integrity/FK PASS and zero active restored sessions/worker credentials. Actual private file and recovery locator are outside D1 and outside Git, under Downloads and ignored `.local/backups`. No backup payload or credential value is included in evidence. Browser access became unavailable after its timeout, so no post-download screenshot is asserted.

System summary reports source watermarks, pending Outbox/oldest due, last internally verified cut, job arrivals/open/accepted/due/expired leases and worker/quota freshness. It explicitly returns unknown DB/Queue usage and null uncalibrated service rate. Internally VERIFIED is integrity of a complete cut; the independent medium receipt above proves this particular downloaded file, not every future export.
