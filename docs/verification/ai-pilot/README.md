# Stage 03 quality pilot

No live pilot has been run. Current-day Gemini usage is UNKNOWN; generation remains inadmissible until a current authorized quota observation is available. This directory defines the review protocol, not completed quality evidence.

`pnpm gate:ai <review.json> <new-score.json>` performs read-only local evaluation. It makes no provider request, enables no paid service and publishes no model approval. The score file is created exclusively; use a new filename for a later actual run and preserve historical FAIL. Raw sources, candidates, responses and annotation files belong in private ignored storage. Git evidence contains hashes, categories and metrics only.

`PilotReview` and `PilotFilm` in `tools/gates/ai-pilot-evaluation.ts` define the input contract. Each film references byte-exact source, manifest, original candidate, canonical, frozen annotations and actual structured provider-response files. Candidate/canonical file and hash are null when the provider produced no result. Failure films remain in the corpus with all frozen important claims and no invented matches. The CLI checks file hashes, response identity/model/usage, raw and repaired validation, exact output denominator, quotes, anchors and inherited timestamps. Element identities are `<canonical module>:<zero-based index>`; every emitted source-backed element needs a human label.

Before any model result is seen, freeze a real source-backed important-claim annotation file with `source_hash`, `manifest_hash`, `frozen_at` and `important_claims`. Each claim has a stable `claim_id`, a human-written `statement`, and one or more contiguous anchor groups `{segment_ids, quote_hash}`. Group hashes refer to the exact source range; noncontiguous spans use separate groups. Record the annotation hash and time before the provider request. Output matching IDs and support labels are added in the later review, without editing the frozen ground truth.

Humans assess support, severity, summary coverage, stance versus usage, literal prediction qualifiers and entity ambiguity. Critical cases include negation, conditions, numbers, reported speech, stance/usage, prediction horizon, ambiguous entities and difficult ASR. Critical reviews require a different independent reviewer and resolved disagreements. LLM self-scores are not ground truth. Boolean null means unknown and prevents PASS.

Stage 03 limited pilot requires at least 12 real films and 40 frozen important claims, supported precision >=95%, important recall >=85%, anchors 100% and zero severe hallucinations. `--full` retains the Master Gate AI minimum of 30 films and 100 important claims. Passing the limited pilot does not pass the full Gate AI. All thresholds are fixed before results. Fixture provenance always reports NOT_RUN; fixture test scores cannot establish provider readiness.

Reports include numerator/denominator, Wilson 95% intervals, raw/wire/canonical validity, deterministic/AI repair counts, known usage with separate unknown counts, and per-film latency/nullable CPU. Wilson intervals are element-level and are explicitly not adjusted for within-film clustering; they are descriptive evidence alongside sample sizes, not a claim of independent samples. Actual quality promotion remains an explicit registry operation for the exact tested scope. Do not create a score or approval without real provider evidence and human review.
