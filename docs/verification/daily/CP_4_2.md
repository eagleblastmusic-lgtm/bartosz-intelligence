# CP-4.2 — authenticated application shell

Stable local acceptance 2026-10-06. Stage 04 remains in progress.

The React shell provides owner-session bootstrap, private-route navigation, browser history, main-focus/scroll restoration, logout and immediate removal of private views on session expiry. Shared requests are aborted when the session is cleared. Only the theme preference is stored in localStorage; no private content is cached there. Navigation exposes implemented Daily, Channels and System views. Light/dark/system themes use shared semantic tokens and one SVG icon family. The original channel intake workflow remains functional.

Six affected Chromium E2E tests PASS: three shell tests, two existing onboarding tests and the bootstrap test. They cover deep links, back/reload, focus, theme persistence, logout, domain 401, idempotent onboarding, malicious text rendering, both themes at 1440/1024/768/360 px, reduced motion, horizontal overflow and computed contrast. Required text contrast remains 4.5:1; focus/borders remain 3:1. Web typecheck, affected ESLint/Prettier, build and diff checks PASS. These tests use API fixtures against actual built assets; they do not establish live provider quality or final Gate U acceptance.

Rendered screenshots are retained locally under `.local/gui/cp-4.2-{light,dark}-{1440,360}.png`. Visual inspection of the light desktop and dark mobile renders confirms readable typography, consistent alignment, wrapped controls, visible empty-state actions and bottom navigation without content overlap. The empty view describes incomplete discovery rather than claiming a complete empty day.

Historical failures: the contrast harness initially could not parse minified shorthand hexadecimal colors; it now expands them before measurement. Collapsed navigation lacked accessible names and now has explicit labels. The initial dark border measured 2.896858:1 and was strengthened to pass the unchanged 3:1 criterion. No acceptance threshold was relaxed.

Calendar, source filters, pagination and stale-read handling follow in CP-4.3. Full notes/Evidence and full System capacity metrics remain later checkpoints. No Stage completion, production deployment of this shell or screen-reader acceptance is claimed.
