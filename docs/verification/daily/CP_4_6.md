# CP-4.6 — exact source Evidence

Stable local verification 2026-10-06. Evidence chips on notes, key points, entities, tools and typed rows open an owner-only drawer. Each discontiguous Evidence ID is a distinct chip/citation; no invented glued span is rendered. The original is the default. API metadata is bound to the accepted production run, immutable outcome hash, VERIFIED original artifact/hash and Ledger UTF-16 anchor. The browser compares quote SHA-256, length, segments, source identity and timing against its completely verified accepted canonical document before showing the citation.

`GET /api/v1/evidence/:id?run_id=...` returns exact `quote_original` inline for a verified single-chunk canonical document up to 32 KiB, with `quote_pl=null`. Larger documents explicitly return `quote_transport=PAGED_CANONICAL`, a null inline quote and a pinned `canonical_reference` to the existing bounded canonical GET. Consumers obtain the full exact quote by Evidence ID from those verified pages; a null inline field never means missing source or a truncated quote. This transport keeps large source/canonical scans out of one Workers Free request and retains one canonical text authority. Master §18 permits the exact immutable text snapshot; no domain schema or Master change is needed. No new quote table/migration or source mutation was introduced.
