# Optional pipelines

V1 defaults to Gemini Free with the implemented local adapter. Profile selection
and execution location are independent. Production still requires an approved
quality scope, fresh free eligibility and conservative quota admission.

Codex Subscription is DISABLED. There is no installed application adapter or
activation route, no qualified execution location, and Gate 0B is NOT_RUN.
No remaining allowance or reserve capacity is claimed. The owner-only System
descriptor displays this inactive state without an unhealthy-provider alert.
ModelRegistry rejects publication of other provider/profile routes in this V1.
The existing AIProvider contract is the extension boundary; Evidence, canonical
Intelligence and Knowledge do not gain a separate provider-specific model.

Implementing an optional adapter later requires official output-only/no-tools
protocol and authorization, explicit activation, capability tests and the
applicable actual Gate 0B before admission or capacity attribution. This document
does not activate a subscription or request credits. Gemini Paid, Antigravity and
Workers AI integrations are not implemented or available fallback routes.
